Place the Thmanyah (ثمانية) web font files here. They are not included because the licence does not allow redistributing the font files.
Get the family from the official Thmanyah font page (free, email required), convert the OTF/TTF files to woff2, and name them:
  sans-400.woff2  sans-500.woff2  sans-700.woff2  serif-display-400.woff2  serif-display-700.woff2
Until they exist the site shows Arabic in Readex Pro. No code change is needed.
